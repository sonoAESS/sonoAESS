# 💫 About Me
Hi, I'm **Antonio Elias Sánchez Soto**, a Bioinformatics Engineer and Neuro-researcher based in Cuba 🇨🇺.

- 🎓 **Education:** Recent graduate in Bioinformatics Engineering from the University of Informatics Sciences (UCI).
- 🏢 **Current Role:** Neuro-researcher at the **Cuban Neuroscience Center (CNEURO)**.
- 🧠 **Research Focus:**
  - EEG & ECoG signal processing and analysis.
  - Inverse problem solutions in neuroimaging.
  - Reference montage optimization.
  - Machine Learning & Deep Learning applied to biomedical data.
  - Systems biology and computational modeling.
- 🌱 **Currently Exploring:** Contributing to open-source neuroimaging tools (Brainstorm, MNE-Python) to improve EEG/MEG/ECoG processing pipelines, inverse solution robustness, and reproducible workflows.
- 💡 **Open to:** Collaborations in computational neuroscience and biomedical ML.
